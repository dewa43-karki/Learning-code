# Projects

A collection of complete, functional applications built while learning programming and web development.

Unlike individual practice exercises, the projects here bring multiple technologies together to solve problems and create interactive applications.

## 📂 Projects

### 1. Tic-Tac-Toe

A classic two-player game where players take turns placing X and O on a 3×3 grid.

**Technologies:**

- HTML5 – Game structure
- CSS3 – Styling and layout
- JavaScript – Game logic and interactivity

**Features:**

- Two-player gameplay (X and O)
- Turn and game-state management
- Win and draw detection
- Reset and play-again functionality
- Responsive design

**What I learned:**

- Implementing game logic with JavaScript
- DOM manipulation and event handling
- Managing turns and game states
- Building interactive user interfaces

**[🎮 Play Tic-Tac-Toe](https://dewa43-karki.github.io/Learning-code/Web-development//Projects/Tic-Tac-Tok/index.html)**

### 2. Rock Paper Scissors

A classic Rock Paper Scissors game where the player competes against the computer.

**Technologies:**

- HTML5 – Game structure
- CSS3 – Styling and layout
- JavaScript – Game logic and interactivity

**Features:**

- Player versus computer gameplay
- Random computer choices
- Automatic winner detection
- Score tracking
- Interactive game interface

**What I learned:**

- Using JavaScript conditional logic
- Generating random choices
- Handling user interactions
- Comparing choices and determining results
- Updating the DOM dynamically

**[🎮 Play Rock Paper Scissors](https://dewa43-karki.github.io/Learning-code/Web-development//Projects/Rock-Paper-Scissor/index.html)**
