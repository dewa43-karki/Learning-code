# Meme Stock Exchange Journey

A terminal-based stock market game written in Python where you can buy and sell fake
stocks, survive random news events, and try to finish with the highest
net worth. Its a designed to make us understand how a stock markrt run and you can ear a high margin profits.

## 📚 What's Inside?

- **Terminal Game where you buy and sell stocks**
- **Starting cash:** 10,000 WON
- **Number of days:** 15
- **Player actions:** buy, sell, skip day, quit
- **Win condition:** highest net worth at the end, with a rank
(for example "Broke" to "Meme")

## Tools Used

- Python
